# apps/web: правила фронтенда

Зона Codex. Общие правила проекта в корневом [AGENTS.md](../../AGENTS.md).

## Что здесь

React 19 + Vite + CesiumJS + Tailwind v4 + Zustand + i18next. Структура `src/` описана в [README.md](README.md).

Текущий код (глобус, верхняя панель, панель слоёв, нижняя строка) является стартовой точкой фазы 0. Его можно свободно перерабатывать, сохраняя правила ниже.

## Правила

- **Производительность глобуса.** Live-объекты (тысячи, обновления раз в секунду) идут `LiveClient` → `LayerRenderer` → примитивы Cesium (`BillboardCollection`, `PointPrimitiveCollection`). Не через React-стейт и не через Entity API. React рендерит только панели и выбранный объект.
- **Данные только по контракту.** Типы и схемы импортируются из `@spyapp/shared`. Входящие WS-сообщения валидируются `ServerMessageSchema`. Нужного поля нет → запрос в спринт, не «временный» локальный тип.
- **Дизайн-система.** Цвета, отступы, шрифты берутся из токенов `packages/ui/src/tokens.css` (через классы Tailwind). Новые переиспользуемые компоненты кладутся в `packages/ui`. Направление описано в `docs/07-design.md`.
- **i18n.** Все строки UI лежат в `src/i18n/ru.ts` и `src/i18n/en.ts`.
- **URL.** Состояние вида (камера, слои, выбранный объект) синхронизируется с URL.
- **Без бэкенда.** Для разработки без реальных данных API будет запускаться в режиме симуляции: `SIMULATE=1 pnpm --filter @spyapp/api dev` (задача B1 в спринте, до её готовности используй фикстуры из `@spyapp/shared/fixtures`).
- **Проверка.** Изменения UI в PR сопровождаются скриншотом или коротким видео.

## Переменные окружения

`VITE_API_URL`, `VITE_WS_URL`, `VITE_CESIUM_ION_TOKEN`: всё из корневого `.env` (см. `.env.example`). Секретов во фронтенде нет и быть не может.
