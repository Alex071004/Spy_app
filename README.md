## Как посмотреть сайт

**Windows, одним кликом:** дважды щёлкните `start.cmd` в корне проекта. Скрипт скачает свежий `main` с GitHub в отдельную папку `.preview` (рабочие копии агентов не трогаются), поставит зависимости, запустит сайт и API и откроет http://localhost:5173. Остановить: Ctrl+C в окне скрипта.

Нужен только Node.js 24: pnpm скрипт при первом запуске поставит сам. Настройки берутся из `.env` в корне (при первом запуске копируется из `.env.example`).

| Что в `.env`                | Что увидите                                                                     |
| --------------------------- | ------------------------------------------------------------------------------- |
| `SIMULATE=1` (по умолчанию) | ~10 000 вымышленных самолётов и ~5 000 судов, движутся сразу                    |
| `SIMULATE=0`                | Реальные самолёты: OpenSky (весь мир) + adsb.lol (где смотрите). Судов пока нет |
| `OPENSKY_CLIENT_ID/SECRET`  | Реальные самолёты обновляются раз в 90 с вместо 15 мин                          |
| `VITE_CESIUM_ION_TOKEN`     | Детальные снимки Земли и рельеф вместо встроенной подложки                      |
| `OFFLINE=1`                 | Совсем без интернета: спутники, поиск мест и фото из встроенных данных          |

Порты 5173 и 4000 должны быть свободны: перед запуском закройте другие копии сайта.

**Вручную (разработка):**

```bash
pnpm install
cp .env.example .env
pnpm dev                  # web :5173 + api :4000
```
