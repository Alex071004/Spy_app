# SpyApp 🛰

> Рабочее название. Свой «Палантир» для любопытных: 3D-глобус с живыми данными планеты и игровым слоем «Операции».

✈ самолёты в небе · ⛴ танкеры в море · 🛰 спутники на орбите · 🚦 пробки в любом городе · 🌍 снимки из космоса по запросу · 🕵️ миссии, расследования и охота за редкими находками

**Статус:** фаза 0, фундамент. См. [роадмап](docs/03-roadmap.md).

## Структура

```
apps/web          фронтенд: глобус (CesiumJS) + UI (React)
apps/api          сервер: коннекторы, состояние мира, WebSocket (Fastify)
packages/shared   общие типы и протокол
packages/game     логика игры (миссии, прогрессия)
packages/ui       дизайн-система HUD
infra/            docker-compose и деплой
docs/             вся проектная документация
```

## Быстрый старт

Требования: Node.js 24 (см. `.nvmrc`), pnpm. Docker понадобится с фазы 4.

```bash
npm i -g pnpm             # или corepack enable (нужны права администратора)
pnpm install
cp .env.example .env      # заполнить ключи по мере подключения источников
# pnpm infra:up           # Postgres понадобится только с фазы 4
pnpm dev                  # web + api
```

> Без `VITE_CESIUM_ION_TOKEN` глобус работает на встроенной подложке Natural Earth II без рельефа.
