# @spyapp/game

Чистая логика игрового слоя «Операции» ([06-gameplay.md](../../docs/06-gameplay.md)): типы миссий, правила проверки, начисление XP, уровни допуска, генерация Daily Intel.

Правило: **никакого I/O**. Функции получают данные на вход и возвращают результат, поэтому логику легко тестировать и использовать и на сервере (проверка), и на клиенте (подсказки, превью). Появится в фазе 4.
