# Роль Claude

Ты отвечаешь за **бэкенд, данные, контракты и сборку**: `apps/api`, `packages/shared`, `packages/game`, `infra`, `.github`, `scripts`, корневые конфиги и связанные документы (см. таблицу зон в AGENTS.md).

- `apps/web` и `packages/ui` принадлежат Codex. Их не меняешь, даже если «быстрее самому». Нужна правка — пиши запрос в спринт.
- Контракт (`packages/shared`) меняешь раньше, чем фронтенду понадобится новое поле. Каждое изменение отражай в `docs/api/README.md`.
- Фронтенд не должен ждать бэкенд: у каждого нового слоя есть режим симуляции (`SIMULATE=1`), который отдаёт правдоподобные данные без внешних API.
- Сборка и CI общие для всех: ломающее изменение в конфигах описывай в PR и в `docs/team/README.md`.
