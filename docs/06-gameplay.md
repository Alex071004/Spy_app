# 06 · Игровой слой: «Операции»

## Фантазия игрока

> _Ты новый аналитик разведцентра. Перед тобой вся планета в реальном времени. Тебе дают задания, ты ищешь, сопоставляешь, находишь. С каждым раскрытым делом растёт твой уровень допуска, и тебе открываются новые инструменты._

Игра **не отдельный режим**, а надстройка над тем же глобусом. Все механики используют **реальные live-данные**, поэтому каждая игра уникальна.

## Прогрессия: уровни допуска

| Уровень | Название        | Что открывает                                 |
| ------- | --------------- | --------------------------------------------- |
| 0       | **Стажёр**      | Базовые слои: самолёты, спутники              |
| 1       | **Аналитик**    | Суда, события, журнал споттера                |
| 2       | **Оперативник** | Запрос спутниковых снимков (N в день), алерты |
| 3       | **Куратор**     | Расследования, создание операций для друзей   |
| 4       | **Директор**    | Всё + особый статус в рейтинге                |

> Базовые слои для просмотра **всегда бесплатны и открыты**. Допуск открывает игровые инструменты и лимиты, а не основу продукта, иначе новичок не увидит «wow».

XP начисляется за: выполненные миссии, Daily Intel, новые записи в журнале, серии дней подряд.

## Механики (по фазам внедрения)

### 🗓 Daily Intel (фаза 4, главная механика возврата)

Одна загадка в день, одинаковая для всех, 3–5 попыток. Варианты формата чередуются:

- **«Где это?»**: показываем спутниковый снимок Sentinel-2 без подписей, игрок ставит метку на глобусе. Очки зависят от расстояния. _(жанр GeoGuessr, но с космическими снимками)_
- **«Что это за борт?»**: силуэт и подсказки (маршрут, высота, страна регистрации), угадать тип самолёта.
- **«Найди судно»**: описание («танкер под флагом X, вышел из порта Y вчера»), найти его на live-глобусе.

Результат шерится текстом без спойлеров:

```
SPYAPP DAILY INTEL #142  🟥🟧🟩  2/3
Допуск: АНАЛИТИК · серия 12 дней
```

### 🎯 Миссии (фаза 4)

Задания, которые проверяются по live-данным. Движок в `packages/game`, проверка на сервере.

| Тип             | Пример                                                    | Проверка                                            |
| --------------- | --------------------------------------------------------- | --------------------------------------------------- |
| **Перехват**    | «Найди любой Boeing 747 над Тихим океаном»                | Игрок выбирает объект, сервер сверяет тип и позицию |
| **Наблюдение**  | «Проследи, куда сядет рейс XX123»                         | Ставка на аэропорт, проверка по факту посадки       |
| **Тёмный флот** | «Найди судно, у которого AIS молчит > 12 ч у побережья X» | Детектор «тёмных» судов (фаза 2)                    |
| **Орбита**      | «Поймай момент, когда МКС пролетает над Москвой»          | Расчёт по TLE                                       |
| **Стихия**      | «Найди самое сильное землетрясение за сутки»              | Данные USGS                                         |

Миссии генерируются по шаблонам из реальных данных («какие редкие объекты сейчас в воздухе?»), поэтому их не надо придумывать вручную каждый день.

### 📒 Журнал споттера (фаза 4)

Коллекционирование, как Pokédex для техники:

- Каждый новый **тип** самолёта или судна, который ты открыл в карточке, попадает в журнал.
- Редкость: обычные (A320), редкие (A380, Ан-124), легендарные (Beluga XL, Boeing E-4, атомные ледоколы).
- Страница коллекции с прогрессом по категориям: «Все типы Airbus», «Ледокольный флот», «Космические станции».

### 🔔 Watchlist и алерты (фаза 4)

- Подписка на борт, судно, тип или зону: «уведоми, когда над моим городом пролетит A380».
- Каналы: web push, Telegram-бот.
- Это и механика возврата, и полезная функция без всякой игры.

### 🕵️ Расследования (фаза 6+)

Многошаговые сюжетные дела на **исторических** данных (replay):

- _«Дело о пропавшем танкере»_: шаг 1: найти последний AIS-сигнал; шаг 2: снимок Sentinel-1 в этот день; шаг 3: найти судно на снимке; шаг 4: где оно всплыло снова?
- Учат реальным OSINT-приёмам, дают «аха-момент» и отличный материал для контента.
- Сначала пишем дела сами, позже открываем UGC для «кураторов».

### 👥 Социальное (фаза 6+)

- Еженедельный рейтинг, рейтинг друзей.
- **Штаб:** общее пространство для нескольких игроков с метками и заметками на глобусе.
- Сезонные ивенты: «Арктическая неделя», «Космический месяц» с тематическими миссиями.

## Эстетика игрового слоя

- Миссии оформлены как **брифинги**: гриф, номер дела, печатающийся текст.
- Выполнение сопровождается штампом «ВЫПОЛНЕНО» / «ДЕЛО ЗАКРЫТО» и звуком (отключаемым).
- Повышение допуска показывается «выдачей нового удостоверения» с позывным игрока. Это же шерится картинкой.

## Чего в игре не будет

- ❌ Миссий про слежку за конкретными частными людьми, их самолётами или яхтами.
- ❌ Наказаний за пропуск дня, давящих на психику (серия может «замёрзнуть» один раз в неделю).
- ❌ Pay-to-win: деньги (если появятся) не дают очков рейтинга.
