# 05 · Источники данных

> ⚠️ Лимиты, цены и лицензии меняются. **Перед подключением источника проверь его текущие условия** и обнови таблицу. Колонка «Коммерция» показывает, можно ли использовать источник при монетизации.

| Источник              | Доступ                               | Обновление | Коммерция                            | Заметки                                                         |
| --------------------- | ------------------------------------ | ---------- | ------------------------------------ | --------------------------------------------------------------- |

| Planespotters.net API | Фото борта по hex / регистрации      | —          | проверить                            | Обязательна ссылка на автора фото, для карточки-досье           |

## Суда (AIS)

| Источник                 | Доступ                              | Коммерция         | Заметки                                                  |
| ------------------------ | ----------------------------------- | ----------------- | -------------------------------------------------------- |
| **aisstream.io**         | Бесплатный WebSocket, API-ключ      | проверить условия | Глобальный поток наземных станций. **Основной кандидат** |
| Global Fishing Watch API | Бесплатно, ключ                     | ❌ некоммерческое | Рыболовство, «тёмные» суда, отличный материал для игры   |
| AISHub                   | Обмен данными (нужен свой приёмник) | ✅ при обмене     | Вариант, когда поставим свой AIS-приёмник                |
| MarineTraffic / Spire    | Платно                              | 💰                | Спутниковый AIS (открытый океан)                         |

Ограничение: бесплатный AIS в основном **наземный**, поэтому в открытом океане суда видны плохо. Учитываем это в детекторе «тёмных» судов.

## Чего мы **не** делаем

- ❌ **Не парсим** Flightradar24, MarineTraffic, Google Earth и другие сайты в обход их API. Это нарушает их условия использования и ломается при любом изменении сайта.
- ❌ Не используем утёкшие или закрытые данные.
- ❌ Не храним данные дольше, чем позволяет лицензия источника.

## Чек-лист подключения нового источника

1. Прочитать условия: лицензия, коммерческое использование, атрибуция, лимиты.
2. Добавить строку в эту таблицу.
3. Положить ключ в `.env.example` (без значения).
4. Реализовать коннектор в `apps/api/src/layers/<id>/connectors/` или прокси в `apps/api/src/core/proxy`.
5. Добавить атрибуцию на страницу «Источники» в UI.
6. Настроить кэш и rate limit, чтобы не превышать квоту даже при росте пользователей.
