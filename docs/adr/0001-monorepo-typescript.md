# ADR-0001 · Монорепозиторий на TypeScript (pnpm + Turborepo)

- **Статус:** принято
- **Дата:** 2026-11-02

## Контекст

Проект состоит из фронтенда, API, воркера сбора данных и общей логики (типы, протокол, игровые правила). Разработчик один, проект долгий. Важно не тратить силы на синхронизацию типов между частями.

## Решение

- Один репозиторий, **pnpm workspaces** + **Turborepo**.
- **TypeScript** во всех частях: `apps/web`, `apps/api`, `packages/*`.
- Протокол WebSocket и форматы данных описываются **Zod-схемами** в `packages/shared` и используются и на клиенте, и на сервере.

## Альтернативы

- **Python (FastAPI) для бэкенда:** богатая гео-экосистема (GDAL, rasterio), но два языка и дублирование типов. Python можно добавить позже отдельным сервисом для тяжёлой обработки снимков.
- **Go для ingest:** быстрее, но преждевременная оптимизация. Node справится с десятками тысяч объектов.
- **Несколько репозиториев:** лишняя сложность для одного разработчика.

## Последствия

- Общие типы бесплатно, рефакторинг одним коммитом.
- Нужно следить за границами пакетов (`packages/*` не импортируют из `apps/*`).
- Если понадобится тяжёлая растровая обработка, появится `services/imagery` на Python, и это нормально.
