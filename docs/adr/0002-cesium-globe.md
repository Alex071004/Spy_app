# ADR-0002 · CesiumJS как движок глобуса

- **Статус:** принято
- **Дата:** 2026-11-02

## Контекст

Нужен настоящий 3D-глобус уровня Google Earth: рельеф, фотореалистичные 3D-здания при приближении, орбиты спутников, управление временем, тысячи движущихся объектов.

## Решение

**CesiumJS** (используем напрямую, с тонкой React-обёрткой вокруг `Viewer`).

- Live-объекты рендерятся через **примитивы** (`BillboardCollection`, `PointPrimitiveCollection`, `PolylineCollection`), а не через Entity API: Entity не тянет 10k+ объектов с частыми обновлениями.
- Обновления live-данных идут напрямую в коллекции Cesium, **мимо React-рендера**.
- Фотореалистичные 3D Tiles (Google) подключаются только ниже заданной высоты.

## Альтернативы

- **MapLibre GL (globe projection) + deck.gl:** отличная производительность для 2D/2.5D и больших датасетов, но нет фотореалистичного 3D-мира и встроенной работы с орбитами и временем.
- **Mapbox GL:** похоже на MapLibre, но платная лицензия.
- **Three.js / react-three-fiber с нуля:** полная свобода, но придётся писать глобус, тайлинг и геодезию самостоятельно, а это месяцы работы.
- **Google Maps JS 3D:** привязка к одному вендору, меньше контроля.

## Последствия

- Бандл Cesium тяжёлый (~несколько МБ), поэтому нужны code splitting и показ «заставки» во время загрузки.
- Возможен гибрид в будущем: deck.gl-слои поверх Cesium для тяжёлых визуализаций (heatmap, плотность трафика).
- Нужен токен Cesium ion (бесплатный тариф) для terrain и базовых снимков.
