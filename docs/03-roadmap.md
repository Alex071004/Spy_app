# 03 · Роадмап

Работаем в паре с Claude, поэтому темп высокий: **одна фаза занимает примерно неделю**, публичный запуск через ~6 недель. Каждая фаза заканчивается демо, которое можно выложить в девлог.

```
Фаза 0  Фундамент         ▓               дни 1–2
Фаза 1  Небо               ▓▓▓▓           неделя 1
Фаза 2  Море и сводка          ▓▓▓▓▓      неделя 2
Фаза 3  Город и снимки              ▓▓▓▓▓ неделя 3
Фаза 4  Операции                    ▓▓▓▓▓▓▓▓▓▓ недели 4–5
Фаза 5  Запуск                                ▓▓▓▓▓ неделя 6
```

Функции подробно описаны в [09-features.md](09-features.md), здесь только порядок.

| Фаза                   | Что делаем                                                                                                                                                              | Демо в конце                               |
| ---------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------ |
| **0 · Фундамент**      | Монорепо, Vite + React + Cesium, Fastify `/health` + `/ws`, дизайн-токены, CI                                                                                           | Тёмный глобус с HUD-координатами           |
| **1 · Небо**           | Самолёты (adsb.lol), спутники и МКС (CelesTrak), стриминг по viewport, карточка объекта, командная строка (`Ctrl+K`), ссылки на вид, i18n                               | «Вся авиация мира на 3D-глобусе»           |
| **2 · Море и сводка**  | Суда (aisstream), землетрясения и пожары, **разведсводка** (лента аномалий: 7700, «тёмные» суда, сильные землетрясения), хвосты треков, карточка-досье PNG, день и ночь | «Глобус сам находит интересное»            |
| **3 · Город и снимки** | Фотореалистичный 3D-город, пробки, веб-камеры, снимок Sentinel-2 по дате, сравнение «до/после», запись видео облёта                                                     | «Ныряем с орбиты в город»                  |
| **4 · Операции**       | Аккаунты, уровни допуска, Daily Intel, миссии, журнал споттера, watchlist и алерты в Telegram                                                                           | Закрытая бета играет несколько дней подряд |
| **5 · Запуск**         | Имя и домен, лендинг, онбординг-брифинг, мобильная версия и PWA, аналитика, страницы источников и правил                                                                | Habr → Reddit → Product Hunt → Show HN     |
| **6+ · Развитие**      | Replay мира, транспорт, запуски ракет, расследования, штаб с друзьями, сеть фидеров                                                                                     | По метрикам                                |

## Как работаем

- **Команда из трёх:** Alex (продукт, ревью, мерж), Claude (бэкенд, данные, сборка), Codex (UI/UX, фронтенд). Зоны и процесс: [AGENTS.md](../AGENTS.md), [docs/team](team/README.md).
- **Контракт раньше реализации.** Функция начинается со схем в `packages/shared`, дальше фронт и бэк идут параллельно. Фронт не ждёт данных: фикстуры и режим симуляции API.
- **Решения по вкусу** (дизайн, механики) принимает Alex.
- **Спринт = фаза.** Задачи текущей фазы лежат в `docs/backlog/sprint-NN.md`.
- **Крупное техническое решение фиксируем ADR** в `docs/adr/`.
- **Инфраструктура появляется по необходимости** ([ADR-0004](adr/0004-lean-start.md)): до фазы 4 нет ни базы данных, ни Docker.
