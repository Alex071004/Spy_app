# 07 · Дизайн-система

## Направление

**Выбрано: «Ситуационный центр»** (2026-11-02). Рабочее место аналитика современного разведцентра: графит, один холодный акцент, точная типографика, высокая плотность данных без визуального шума. Характер создают детали (уголки панелей, прицельные рамки, моноширинные цифры, сетка), а не декор.

Отклонённые варианты: «Фосфор» (радарный ЭЛТ) и «Досье» (бумажные карточки). Радарную развёртку можно позже вернуть как пасхалку.

### Типографика

- **Inter** (variable) для интерфейса: базовый размер 13 px, шкала 11 / 12 / 13 / 15 / 18 / 24.
- **JetBrains Mono** для чисел, координат, времени, позывных. Всегда `tabular-nums`.
- Метки разделов пишутся заглавными, 11 px, разрядка `0.14em`, цвет `--text-muted`.
- Шрифты подключаются локально через `@fontsource`, без запросов к Google.

### Форма и детали

- Скругления 2 px: интерфейс «технический», а не «дружелюбный».
- Панели получают тонкую рамку и акцентные **уголки** 8 px по углам вместо обводки целиком.
- Сетка отступов кратна 4 px.
- Выбранный объект на глобусе обводится прицельной рамкой цвета `--accent`.
- Глобус: снимки Земли затемнены и слегка обесцвечены (brightness ≈ 0.6, saturation ≈ 0.7), поэтому цветные объекты читаются поверх. Атмосфера и звёзды остаются.

## Технический каркас

| Что             | Решение                                                                                                                                                                                             |
| --------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Токены          | CSS-переменные в `packages/ui/src/tokens.css`, три уровня: **палитра** (`--gray-900`) → **роли** (`--surface-panel`, `--text-muted`, `--accent`) → **слои** (`--layer-aircraft`, `--layer-vessels`) |
| Стили           | **Tailwind CSS v4**: тема через `@theme`, которая читает те же переменные. Смена направления затрагивает один файл токенов                                                                          |
| Примитивы       | **Radix UI** (диалоги, меню, тултипы, переключатели), стилизуем сами. Компоненты в духе shadcn/ui: код лежит у нас, а не в `node_modules`                                                           |
| Иконки          | **Lucide** для UI; свои SVG-силуэты для техники (типы самолётов, классы судов)                                                                                                                      |
| Шрифты          | Inter + JetBrains Mono (см. «Типографика» выше)                                                                                                                                                     |
| Цвет на глобусе | Цвета слоёв подбираются под контраст и на тёмной подложке, и на спутниковых снимках. Иконки объектов с тёмной обводкой                                                                              |
| Тема            | Только тёмная (продукт про «ночной ситуационный центр»). Светлую не делаем                                                                                                                          |
| Движение        | Длительности `--dur-fast/base/slow`, уважаем `prefers-reduced-motion`                                                                                                                               |
| Доступность     | Контраст текста ≥ 4.5:1, фокус видим, всё доступно с клавиатуры                                                                                                                                     |

## Компоненты `packages/ui`

| Группа    | Компоненты                                                                                                   |
| --------- | ------------------------------------------------------------------------------------------------------------ |
| Основа    | `Panel` (полупрозрачная панель поверх глобуса), `Button`, `IconButton`, `Toggle`, `Input`, `Kbd`, `Tooltip`  |
| Данные    | `DataRow` (подпись + моно-значение), `Stat`, `Coord`, `Timestamp`, `Badge`                                   |
| Глобус    | `LayerToggle` (иконка, цвет слоя, счётчик), `ObjectCard`, `IntelItem` (событие сводки)                       |
| Характер  | `Stamp` (гриф), `CornerFrame` (уголки панели), `Reticle` (прицельная рамка), `Briefing` (печатающийся текст) |
| Навигация | `CommandBar` (`Ctrl+K`), `Sheet` (нижняя шторка на мобильных)                                                |

## UX-правила

1. Глобус виден меньше чем за 3 секунды, данные догружаются поверх.
2. Регистрация нужна только для игры.
3. Любое состояние хранится в URL.
4. Горячие клавиши: `Ctrl+K` открывает командную строку, `L` слои, `I` сводку, `Esc` закрывает, `Space` ставит паузу.
