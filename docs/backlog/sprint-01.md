# Спринт 01 · Фундамент + Небо (фазы 0–1)

**Цель:** живой 3D-глобус с самолётами и спутниками, командной строкой и карточкой объекта.
**Демо:** видео «вся авиация мира на 3D-глобусе» для девлога.

Владельцы зон и процесс: [AGENTS.md](../../AGENTS.md), [docs/team](../team/README.md). Статус: ⬜ не начато · 🟨 в работе · ✅ готово.

## Сделано (фаза 0)

- ✅ Монорепо pnpm + Turborepo, ESLint, Prettier, CI
- ✅ `apps/web`: Vite + React + CesiumJS, базовый HUD (координаты, высота, UTC, панель слоёв)
- ✅ `packages/ui`: токены «Ситуационного центра», `Panel`, `DataRow`, `Kbd`
- ✅ `apps/api`: Fastify, `/health`, `/ws` с валидацией сообщений
- ✅ Контракт v1 в `packages/shared` (Zod), фикстуры, тесты
- ✅ Репозиторий на GitHub, правила команды
