# 09 · Функционал

Приоритет: **★ фирменная** функция (из-за неё приходят и рассказывают другим) · **●** обязательна к запуску · **○** после запуска.

## ★ Фирменные функции

Именно они делают продукт «Палантиром», а не очередным трекером.

| Функция                 | Суть                                                                                                                                                                                                                                                                                                                                    | Фаза |
| ----------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---- |
| **★ Разведсводка**      | Живая лента справа: система _сама_ находит интересное и пишет короткие донесения. «07:42 UTC · Борт RYR4KP подал сигнал 7700 над Бискайским заливом». Клик переносит камеру к объекту. Детекторы: аварийные сквоки, круги ожидания, резкое снижение, «тёмные» суда, сильные землетрясения, новые пожары, пролёт МКС над крупным городом | 2    |
| **★ Командная строка**  | `Ctrl+K` открывает терминал оператора: `track AFL1234`, `goto Токио`, `layer vessels tankers`, `intel quakes 24h`, `snap 55.75 37.61 2026-10-01`. Автодополнение, история. Быстрее мыши и сразу задаёт «шпионский» тон                                                                                                                  | 1    |
| **★ Досье объекта**     | Карточка в стиле личного дела: фото (Planespotters API), тип, оператор, маршрут, хвост трека, гриф. Кнопка «Рассекретить» делает PNG для соцсетей                                                                                                                                                                                       | 1–2  |
| **★ Снимок по запросу** | Выделил рамку, выбрал дату и получил кадр Sentinel-2. Шторка «до/после» поверх 3D                                                                                                                                                                                                                                                       | 3    |
| **★ Daily Intel**       | Ежедневная загадка (место по снимку / тип борта / найти судно), шеринг эмодзи-сеткой                                                                                                                                                                                                                                                    | 4    |

## Сознательно не делаем

- Отдельные «экраны» и дашборды: всё происходит на глобусе.
- Слежку за конкретными частными людьми (см. [08-legal-ethics.md](08-legal-ethics.md)).
- Регистрацию для просмотра: она нужна только для игры.
